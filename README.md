# Aryan-Sisodiya_1097_IILM-GN
AI Chatbot – Python (OpenRouter)

This project is an AI-based chatbot developed in Python using OpenRouter’s Large Language Model (LLM) API. The chatbot interacts with users through a desktop graphical interface (Tkinter) and generates intelligent, real-time responses.

🔹 Project Purpose

Demonstrate practical use of Generative AI

Build a responsive chatbot with a clean GUI

Optimize response speed and user experience

📁 Project Files Overview

main.py Entry point of the application. It initializes the Tkinter window and launches the chatbot interface.

gui.py Handles the graphical user interface, user input, and message display. Uses multithreading to keep the GUI responsive during API calls.

bot.py Manages communication with the OpenRouter API. Sends user messages, receives AI responses, and improves speed by limiting context size and adding request timeouts.

⚡ Key Features & Enhancements

AI-powered conversational responses

Non-blocking, smooth GUI interaction

Faster response time through optimized API handling

Typing indicator for better user experience

Modular and readable code structure
